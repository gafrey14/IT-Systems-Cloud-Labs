# Active Directory Domain Services (AD DS) Lab

## Objective
Set up an Active Directory domain environment using Windows Server virtual machines and join a Windows client to the domain.

## Environment
- **Virtualization:** VMware
- **Server OS:** Windows Server
- **Client OS:** Windows client VM
- **Services:** Active Directory Domain Services (AD DS), DNS

## Tasks Completed
- Installed the Active Directory Domain Services role.
- Promoted the Windows Server to a domain controller.
- Created a new Active Directory forest and domain.
- Configured DNS for the Active Directory environment.
- Verified domain name resolution.
- Joined a Windows client VM to the domain.

## Results
Established an Active Directory domain environment with a domain controller, DNS name resolution, and a Windows client joined to the domain.

## Key Takeaways
- Learned how Active Directory centrally manages users, computers, authentication, and access to network resources.
- Practiced promoting a Windows Server to a domain controller and creating a new forest.
- Learned the importance of DNS in locating domain controllers and supporting domain authentication.
- Gained hands-on experience joining a client computer to an Active Directory domain.

## Skills Demonstrated
Active Directory, Windows Server Administration, DNS Configuration, Domain Controller Deployment, Virtualization, and Windows Domain Management.
